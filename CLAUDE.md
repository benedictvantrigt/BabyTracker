# Baby Tracker

  when a phase is finished.
- Feature backlog: GitHub issues, one milestone per phase. Reference the issue ("Closes #N")
  in the commit or pull request that finishes it.
- Release history: `CHANGELOG.md`. Versioning and branches: README, "Versions and branches".
- App instructions (Expo): `mobile/AGENTS.md`.
